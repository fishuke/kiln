---
name: docs-style
description: Kiln docs page template and voice.
---
- Frontmatter: title, description, owner, section.
- First line: a one-sentence answer to the page's question.
- Short sentences, plain words, American English, no marketing.
- Show real file paths and YAML keys from the code; generated reference pages come from `pnpm docs:gen`.
- End with a Related pages list of relative links.
