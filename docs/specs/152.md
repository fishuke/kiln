# #152: Platform cost next to compute and inference

Request (2026-11-10): the Spending tab and the `/costs/*` endpoints split cost into compute
and inference only, and `platform` is always 0. Warp Factories splits cost per PR into
Compute, Platform and Inference.

## Decision: what "platform" means in self-hosted Kiln

There is no Kiln bill: you run it on your own machines with your own keys (ADR-007). So
platform cost is not a fee. It is what Kiln spends on its own machinery, as opposed to the
agents doing the work:

- **Judging**: the judge cost of every score recorded on a run (`Score.costUsd`), attributed
  to the scored run. A PR's platform cost is the judge cost of its runs' scores.
- **Self-improvement and evaluation**: the whole cost of `improver` and `benchmark` runs.
  These rarely belong to a PR, so they show up in the spend breakdowns, not in cost per PR.

Inference is the run's own model spend for every other run kind (`work`, `replay`,
`planner`). Compute does not change: sandboxes run on your hardware and Kiln does not price
them, so it stays 0 unless a run reports `computeCostUsd`.

`total = compute + platform + inference`. Cost per PR, top PRs and PR size buckets now
include platform, so they rise by the judge cost of scored runs.

No definition, schema or ADR change: the numbers come from runs and scores already stored.
A configurable platform fee was rejected: it needs new configuration and would be invented
money in a self-hosted product.

## Acceptance criteria

- AC1 `/costs/per-pr`, `/costs/per-pr/top`, `/costs/per-pr/by-size` and `/costs/breakdown`
  return `dollars.platform` by the rule above, and `dollars.total` adds it.
- AC2 The dashboard's cost breakdown chart has three series: Compute, Platform, Inference.
  Spend by agent shows platform in each row's detail line. Cost per PR includes platform.
- AC3 `docs/site/measure-and-improve/metrics.md` explains the three components.

## Packages

- `packages/engine` (`factory-metrics.ts`): split each run's cost into platform and
  inference; add score cost per run.
- `apps/web` (`dashboard-data.ts`, `dashboard-view.tsx`): same split from runs and scores.
