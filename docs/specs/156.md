# #156: Docker sandboxes work in local development

## Problem

Since ADR-017 every run needs a sandbox. With `pnpm dev` and a `backend: docker` runner that lists `egress` hosts, a run fails: no `kiln-egress` network or proxy, the dev compose proxy has no internet, the proxy does not know the run's hosts, and `http://localhost:4000` inside a sandbox is not the API.

## Behaviour

- `pnpm dev` runs `docker compose up -d --build egress-proxy` first (Docker backend only, skipped when `KILN_EGRESS_PROXY` is set). When that fails it prints the command and goes on.
- `docker-compose.yml`: the proxy is on the default network (internet) and on `kiln-egress` (internal); it resolves `host.docker.internal` on Linux too. The `api` service sets `KILN_SANDBOX_URL=http://api:4000`.
- Docker provider (`packages/sandbox`): before `docker run`, find the proxy (`docker ps` by label `kiln.egress-proxy=1` and the egress network). Missing: `the sandbox egress proxy is not running on the Docker network kiln-egress. Start it with: docker compose up -d egress-proxy`. After `docker run`: read the sandbox's address, `docker exec <proxy> kiln-egress-rule set <address> <allow> <deny>`. On destroy: `kiln-egress-rule drop <address>`. See ADR-018.
- Proxy image (`deploy/egress-proxy`): squid asks `kiln-run-acl` per request; it reads `/etc/squid/runs/<address>.allow|deny`. Only IPv4 lines of `/etc/hosts` are used.
- Sandboxes get both `HTTP_PROXY`/`HTTPS_PROXY` and the lower-case spellings (curl and git ignore upper-case `HTTP_PROXY`).
- `KILN_SANDBOX_URL` (API config, `KilnOptions.sandboxUrl`): the guard URL, the Kiln MCP server URL, `KILN_URL` and the Kiln host in a run's allowlist use it. Default: the public URL, or `http://host.docker.internal:<port>` for a localhost public URL on Docker.

## Not in scope

Per-pod rules on Kubernetes (the proxy there keeps the server list). Model credentials.

## Tests

`packages/sandbox/src/index.test.ts` (rule, provider call order, missing proxy), `packages/engine/src/core.test.ts` (sandbox URL host in the allowlist), `apps/api/src/github-enterprise.test.ts` (URL choice).
