How it works

A pipeline for every change an agent makes

CI/CD made shipping code repeatable: every commit is built, tested and gated the same way. Kiln does that for agent work, from the first triage to the merged pull request.

Intake

Issue, Slack thread or ticket

Triage

Foreman picks the shortest path

Spec

Acceptance criteria you approve

Build

Agent codes in a sandbox

Verify

Tests, video per criterion

Preview

A live URL you accept

Review & merge

Reviewed PR, a person merges

Agents do the work You approve at the gates Small, clear changes skip the spec

Classic CI/CD

  • inputA commit a person wrote
  • pipelineBuild, test, deploy
  • defined inYAML in your repo
  • gateGreen checks and a code review

Kiln

  • inputAn issue, a Slack thread, a ticket
  • pipelineTriage, spec, build, verify, preview, review
  • defined inA factory tree in a repo you own
  • gateSpec approval, preview acceptance, a person merges

Built for teams

Agents do the work. People stay in charge.

Factories as code

Agents, automations, pipelines, scorers and skills live in a Git repo you own. Changes are reviewed like code and apply on merge.

Sandboxed runs

Every run starts in a Docker or gVisor sandbox behind an egress allowlist. Every shell command passes a guardrail.

Agents never merge

Agents push only kiln/* branches with short-lived tokens. No agent identity can approve or merge.

Evidence on every PR

Test output, a video for each acceptance criterion and a preview URL are attached to the pull request.

Scorers and self-improvement

Scorers grade every run. Repeated failures turn into definition PRs, replayed against the failing runs first.

Cost you can see

Spend per agent, per run and per merged PR: compute, inference and platform, with team budgets.

Quickstart

Running in two minutes

One process, a data folder and Docker. Demo data, a git-backed forge and scripted agents are built in, so you can see the whole lifecycle before connecting anything.

  • Local first. No accounts needed to try it.
  • Scale out with Docker Compose or Helm when your team joins.
  • Your data stays on your infrastructure.
~/kiln
$ pnpm install && pnpm dev
✓ API on :4000 (demo data) · web on :3000

# use real models
$ export KILN_AGENTS=real ANTHROPIC_API_KEY=…

# define a factory as code
$ pnpm kiln init my-factory --template sdlc
$ pnpm kiln apply my-factory
✓ applied my-factory

$ pnpm kiln send "Fix the typo in the README"
→ triaging → building → reviewing
✓ PR opened · waiting for a person to merge
